# Ограничения

1. Область работы - только эта папка проекта. За её пределы не выходить,
   файлы вне неё не читать и не изменять без явной просьбы.
2. Не трогать `.env`, ключи и деплой-скрипты без подтверждения.
3. Не выполнять разрушительные команды без явного согласия.
4. Не выводить секреты в открытом виде.
5. Не коммитить секреты и личные данные: `.env`, токены, профили, базы -
   в `data/`, закрытой `.gitignore`.
6. Пути внутри проекта - только относительные.

## Для агента-исполнителя (Antigravity и другие)

7. Работать только по выданному ТЗ; файлы вне списка ТЗ не трогать.
8. Перед сдачей прогнать проверку проекта; без зелёного не сдавать.
9. Архитектурных решений не принимать: упёрся - вернуть вопрос в `STATE.md`.
10. Удаление файлов и откат чужих правок - только с подтверждения.
11. Снимок `snapdiff.py` не трогать и не пересоздавать. Сдавать вывод
    `snapdiff.py diff` целиком, своими словами не пересказывать.
