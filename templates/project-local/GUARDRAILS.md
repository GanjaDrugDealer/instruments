# Ограничения

1. Область работы — только эта папка проекта. За её пределы не выходить,
   файлы вне неё не читать и не изменять без явной просьбы.
2. Не трогать `.env`, ключи и деплой-скрипты без подтверждения.
3. Не выполнять разрушительные команды без явного согласия.
4. Не выводить секреты в открытом виде.
5. Не коммитить секреты и личные данные: `.env`, токены, профили, базы —
   в `data/`, закрытой `.gitignore`.
6. Пути внутри проекта — только относительные.
