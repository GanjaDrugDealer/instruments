# agy CLI на Mac

Состояние на 2026-11-03 (Стамбул): установка готова, первый запуск ожидает принятия условий человеком. Подписка, квота и реальный ответ модели пока не проверены.

- Официальный установщик: https://antigravity.google/cli/install.sh
- Установлена версия 1.4.12, darwin_arm64; SHA-512 архива проверен официальным установщиком.
- Бинарник: `~/.local/bin/agy`; установщик добавил PATH в `~/.zprofile`.
- Скилл `antigravity` подключён в `~/.codex/skills/antigravity` ссылкой на общий источник.
- Помощник из `skills/shared/antigravity/scripts/agy.py` скопирован в `~/.local/share/agy-helper/agy.py`; запуск: `~/.local/bin/agy-helper`.
- Проверки `test_agy.py` прошли: схема ответа, квота, блок после 429, замок и приоритет картинок. Это проверки с подставным agy, без вызова модели.
- Первый запуск открыт в Terminal через `~/.local/bin/agy-setup.command`. Условия и выбор передачи данных принимает пользователь.

## Завершение настройки

1. В открытом терминале выбрать передачу данных, принять условия; войти в свой Google-аккаунт, если потребуется.
2. Проверить `agy -p /usage --print-timeout 45s` и `agy models`. Не считать наличие Pro подтверждённым до проверки.
3. Сделать короткий пробный вызов через помощник; для JSON передать `prompt` и `schema` через stdin в `agy-helper text`.
4. Для экономии токенов основного агента передавать объёмную механическую работу Gemini пачками; основной агент проверяет результат. Общая квота аккаунта учитывается помощником; при 429 не повторять в цикле.

Не использованы API-ключи, прокси OAuth и автоматическое принятие разрешений. Данные входа не копировались. Системные настройки модели и доверие ко всем проектам не менялись.
