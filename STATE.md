## Yandex AI Studio

26.11.2026 (Стамбул) добавлен общий скилл [yandex-ai-studio](skills/shared/yandex-ai-studio/SKILL.md).
Портативный yc 1.48.0 для Windows проверен по контрольным значениям Yandex Object Storage.
При запуске портативной копии на этом ПК Windows отклоняла запись журналов и профиля в стандартные папки. Для портативной копии скилл поддерживает отдельный домашний каталог `bin/yandex-cloud/profile` и временную папку внутри него.
Вход передаётся самому `yc`: проверка размера окна через stdin блокировала обычный PowerShell.
В журнале реального входа обнаружен отказ механизма открытия браузера. Открытие корня локального сервера без параметров переводит в веб-консоль, а `yc` сообщает `failed to fetch state`. Режим `--manual-browser` удалён. Для следующей живой проверки нужно завершить штатный вход в `yc`. Cloud Shell в выбранном облаке вернул отказ в доступе.
26.11.2026 (Стамбул) штатный `yc init` с Chrome по умолчанию дошёл до ожидания браузера, но форма входа не открылась и IAM-токен не получен. Исходные ассоциации Windows восстановлены и сверены.
26.11.2026 (Стамбул) Edge открыл локальную тестовую страницу с исходным и подменённым `USERPROFILE`. У портативного `yc.exe` в `bin/` подтверждена метка Low. При реальном входе `yc` стартует на Low, основное окно Edge работает на Medium, подтверждение входа в CLI не получено.
26.11.2026 (Стамбул) проверенная сборка `yc` 1.48.0 установлена в `%USERPROFILE%\yandex-cloud\bin`. `yc config profile list` завершился с кодом 0. Стандартный `yc` и Edge работают на Medium. `yc init` открыл вкладку Yandex Cloud Auth и ждёт подтверждения. Скилл находит стандартную установку Windows даже без записи в `PATH`.
