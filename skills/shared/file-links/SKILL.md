# Ссылки на файлы — только полный путь

В ответах пользователю ссылка на файл — **только абсолютный путь**, пробелы как `%20`.

| Где | Как |
|---|---|
| Mac | `[STATE.md](/Users/artemganza/Desktop/AI%20Projects/Claude/youtube-shorts-cs/STATE.md)` |
| Windows | `[STATE.md](file:///C:/AI%20Projects/<проект>/STATE.md)` — схема `file:///`, диск `C:/`, прямые слэши, пробелы `%20`, кириллица как есть: `[план](file:///C:/AI%20Projects/Claude/Контент/план.md)` |

Нельзя: `[STATE.md](STATE.md)`, `docs/…`, `./…`, `~/…`.

**Почему.** Приложение открывает относительную ссылку от папки, где запущена сессия,
а не от папки проекта. Сессия, начатая в одной папке и работающая в другой, даёт
«couldn't find this file» (так было 2026-09-25).

Путь в тексте (не ссылкой) — тоже полный, чтобы его можно было скопировать.
