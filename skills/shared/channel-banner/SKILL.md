# Шапка YouTube-канала

Опыт 2026-09-28/29 (4 канала CS-шортсов, проект content-manager). Первая версия надписей через ffmpeg
`drawtext` была забракована владельцем: «очень криво», «получилось как 2010». Всё ниже — чтобы так не было.

## 1. Зона видимости — главное правило

Шапка 2560×1440 (Gemini отдаёт 2752×1536 — подходит, ставится `object-fit: cover`). Видна не вся:

| Где | Что видно (px на 2560×1440) |
|---|---|
| Телевизор | всё |
| Компьютер | вся ширина × полоса **508–931** по высоте |
| Телефон («на всех устройствах») | **507–2053 × 508–931** — прямоугольник 1546×423 по центру |

Лицо **целиком** (от макушки/очков до подбородка) и надпись целиком — внутри 1546×423, с запасом ≥30 px.
Лицо обычно длиннее, чем кажется: на портрете «голова и плечи» подбородок ≈ 0,77–0,80 высоты кадра.

**Превью обрезки** — всегда перед сдачей, одной картинкой (сверху компьютер, снизу телефон):
```
ffmpeg -i banner.jpg -filter_complex "[0]split[x][y];[x]crop=iw:ih*0.293:0:ih*0.3535,scale=1200:-2[d];[y]crop=iw*0.603:ih*0.293:iw*0.1985:ih*0.3535,scale=1200:-2[m];[d][m]vstack" -frames:v 1 banner_views.jpg
```
Класть рядом с шапкой как `<имя>_views.jpg` — владелец смотрит их сам.

**Ложная тревога:** в YouTube Studio → «Настройка баннера» серая подпись «Зона, которую видно на всех
устройствах» лежит поверх верхней части надписи. Это не обрезка: на канале подписи нет. Рамки Studio совпадают
с таблицей выше. Отвечать спокойно, со ссылкой на `_views.jpg`.

## 2. Картинка-основа

- Картинки из Gemini: лицо почти всегда слишком крупное и справа → режется. Перегенерация в том же чате:
  «Zoom out and recompose this banner: make the woman noticeably smaller… whole head… inside the middle third of the
  image height… Extend the background… Keep her face exactly the same. 16:9, no text.»
- Если шапки не годятся, а аватар хороший — **собрать шапку из аватара**: портрет ~480 px (так голова влезает в 423),
  края растворить маской в фоне того же цвета. Цвет фона снять с аватара (ffmpeg → `scale=50:50` → rawvideo → пиксели
  у головы и по краям), фон шапки — radial-gradient от этого цвета к темнее. Маска — пересечение двух:
  `radial-gradient(ellipse 50% 60% at 50% 50%, #000 76%, transparent 100%), linear-gradient(to bottom, #000 80%, transparent 97%)`
  + `mask-composite: intersect` (+ `-webkit-mask-composite: source-in`). Проверить края с поднятым контрастом (`eq=contrast=1.6`).
- Отрезанная по контуру голова на пустом фоне («голова в вакууме») — брак, не использовать.
- Сверять лицо на картинке с исходным кадром: генератор расширяет челюсть и губы.

## 3. Надпись — только в Claude Design

Холст типа Design: один артборд = одна шапка 2560×1440, фон — загруженный ассет (`<img>` absolute + `object-fit: cover`),
надпись — разметка поверх. Давать 2–3 варианта рядом, по ряду на канал, заголовок-заметка над рядом.
В каждый артборд — tweak `safeZone` (boolean, по умолчанию выкл.): пунктир «компьютер» + красная рамка «телефон».

**Место под текст — мерить, а не на глаз.** Свободная область (облачко, стена) — по пикселям: картинку ужать до 256×144,
по строкам найти протяжённость нужного цвета вокруг центра области, умножить на 10. Текст — внутри этого прямоугольника
∩ телефонной зоны, не на лице и не на руках.

**Типографика, которая сработала (все с кириллицей на Google Fonts):**
| Характер | Шрифты | Приём |
|---|---|---|
| дерзкий гламур | Unbounded 800 + Playfair Display italic 700 | «СМОКИ» гротеском, «Помада» курсивом, под словом мазок-помада (скруглённый повёрнутый прямоугольник) |
| граффити, ночь | Rubik Wet Paint + Rubik Mono One | главное слово мокрой краской, второе — «наклейка» на тёмной полосе, всё под наклоном −5° |
| комикс (запасной) | Russo One | обводка + жёсткая тень, rotate + skew |
| мягкий, уютный | Caveat 700 + Unbounded 500 | рукописно на кремовой «записке» со скотчем, или светлым по фону с тёплой тенью |
| строгий минимализм | Onest 800/400 | строчные, трекинг −4 px, шкала/линейка SVG-штрихами |

Не делать: Pacifico и «свадебные» скрипты (выглядит устаревшим), текст прижатый к левому краю облачка, моноширинный
шрифт с пробелом (пробел выходит двойным), эмодзи на картинке (рисовать SVG-иконку: сердце, бровь). Тень текста —
мягкая (`0 6px 36px rgba(…, .45)`) или жёсткая офсетная в фирменном цвете, не серая размытая.

Правка холста: перед изменением перечитать файлы с холста — владелец двигает надписи сам; публиковать только изменённые
файлы, `canvas.json` — только при новых артбордах.

## 4. Выгрузка в JPG

Экспорт делает агент, не владелец: копия артборда → обычный HTML → **локальный Google Chrome headless** 2560×1440 → JPG.
Эталон — `scripts/design-render.py` в проекте content-manager (копировать в проект, рядом папка `fonts/`):
убирает `support.js`, `<sc-if>`, `<x-dc>/<helmet>`, подменяет `/_blob/<id>` на локальный файл, пишет JPG + `_views.jpg`.

- **Шрифты — локально**, через `@font-face` на файлы в `fonts/`. Google Fonts в headless грузятся через раз:
  Caveat, Unbounded, Russo One молча подменялись системным шрифтом. После рендера — посмотреть кроп надписи крупно.
- Кириллический woff2: запросить `https://fonts.googleapis.com/css2?family=<Имя>:wght@700` с User-Agent Chrome,
  взять `src` из блока `/* cyrillic */`.
- JPG `-q:v 2` → 100–850 КБ (лимит YouTube 6 МБ).
- Имена: `chN_banner_final.jpg`; варианты на выбор — `chN_banner_new_<вариант>.jpg`, запасной — `chN_banner_spare.jpg`.
  Старое не удалять — переименовывать.

## Чек-лист сдачи

1. Лицо и надпись целиком в 1546×423 на `_views.jpg` (телефон снизу).
2. Шрифт отрисовался тот, что задуман (кроп крупно), кириллица на месте.
3. Надпись не касается краёв свободной области, лица, рук.
4. Файл в папке оформления владельца, ссылка абсолютным путём, картинку отправить владельцу.
5. Холст обновлён теми же исходниками, что ушли в рендер.
