# Тегирование реакций по эмоции

Цель: каждому ролику-реакции (1 ролик = 1 эмоция) дописать в имя 1–2 тега эмоции,
чтобы монтажёр находил реакцию под тему ролика поиском в Finder.

Кадры получать скиллом **`video-frame-sheets`** (листы в пиках движения).
Здесь — только как их читать и что делать с результатом.

## Словарь

Живёт в проекте: `docs/*_tags.md`. Теги — только оттуда. Если словаря нет —
сначала составить его с пользователем под его темы.

Два слоя:
- **эмоция** — в имени файла: `IMG_9477_SHOCK.MOV`, `IMG_9514_LOL_NICE.MOV`;
- **тема** — только в таблице «тема → эмоции». Новая тема = новая строка,
  файлы не переименовываются.

Теги, описывающие ситуацию, а не лицо (`GG`, `LowSkill`, `BadGame`), в имя не пишутся —
это темы.

## Порядок

1. Листы — `video-frame-sheets`. Концовка «пальцами в комменты» (одинаковая во всех
   роликах) — не эмоция, не учитывать, даже если попала в кадр.
2. Имена файлов в папке до оценки **не читать** — если уже подписаны, тест не слепой.
3. Таблица «было → стало → уверенность» в `out/<дата>_proposal.tsv`
   (колонки через таб; `ok` / `?`). Пользователю — две группы: уверен / проверьте.
4. Сомнительные разбирает пользователь (часто по звуку). Описание не ложится в
   словарь — предложить новый тег; добавить только после «да» в `docs/…_tags.md`
   и строку эмоций в `CLAUDE.md` проекта.
5. Переименование — только после явного «ок» на итоговую таблицу. Исходники
   не удалять и не перекодировать.

## Как читать кадры

Жест руками важнее мимики:

| Что видно | Тег |
|---|---|
| рука на голову / лоб | `FACEPALM` |
| ладонь у рта + круглые глаза, открытый рот | `SHOCK` |
| «ОК», палец вверх, спокойная улыбка | `NICE` |
| ладонь вверх «ну и?», жест «чуть-чуть» | `MEH` |
| смех, прикрывает рот смеясь | `LOL` |
| кривится, отмахивается | `CRINGE` |

- Прикушенная губа, надутые губы, лёгкая ухмылка — **неоднозначны**
  (в практике оказывались и `WOW`, и `NICE`, и `MEH`). Ставить `?`, не угадывать.
- Эмоция на голосе («я в шоке», «кошмар») на лице выглядит мягче, чем есть. Если лицо
  «почти» что-то показывает — `?`.

## Опыт первого прогона (reaction-tagger, 2026-09-25, 26 роликов)

- Равномерные 3 кадра: 3/4 на слепом тесте.
- Равномерные 5 кадров: 17 уверенных, 9 сомнительных. В «уверенных» ошибок не нашлось;
  в сомнительных промахи — `HYPE` вместо `LOL_NICE`, `SUS` вместо `NICE` (пропущен жест).
- Пики движения: подтвердили 22, нашли пропущенный палец вверх ещё в одном ролике.
- Разбор промаха: проект reaction-tagger, `docs/2026-09-25_miss-9517.md`.
