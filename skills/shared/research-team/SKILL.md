# Режим поиска командой

Проверено 2026-10-03 (content-manager: «где брать CS-ролики для конвейера»): 4 разведчика + злой редактор,
~40 мин, ~470 тыс. токенов субагентов. Дало то, что один агент бы пропустил: правило YouTube, ломающее
спонсорский баннер, и путь «свой рендер из демок» вместо чужих роликов.

## Состав

| Роль | Модель | Сколько | Задача |
|---|---|---|---|
| **Ведущий** (ты) | основная | 1 | контекст, нарезка направлений, сверка фактов, синтез, запись |
| **Разведчик** | `sonnet`, `general-purpose`, фон | 3–5 | одно направление, веб-поиск, таблица вариантов |
| **Злой редактор** | `opus`, `general-purpose` | 1 | разнести черновик плана: риски, объём, упущенное, порядок |

Субагентов запускать **только если владелец попросил** (команду, субагентов, брейншторм). Иначе — сам, по шагам ниже.

## Порядок

1. **Контекст (5 мин, сам).** Прочитать STATE, ограничения (GUARDRAILS), решения владельца по теме, бэклог идей.
   Выписать: что уже отвергнуто, железо и люди, жёсткие правила (права, бренд, клиентские аккаунты).
2. **Нарезать 3–5 направлений без пересечений.** Пример: «про-матчи и демки» / «стримеры» / «свой контент и сообщество» /
   «тренды и правила платформы». Одно направление — про **правила и риски** обязательно.
3. **Запустить разведчиков параллельно** (одно сообщение, все в фоне). Промпт — шаблон ниже. Сказать владельцу
   в 3–4 строках, кто что ищет.
4. **Пока ждёшь — каркас плана** в голове; отчёты разведчиков приходят сообщениями — не читать их output-файлы.
5. **Сверить по первоисточнику** всё, что меняет план (запреты, правила площадки, цифры квот): WebFetch официальной
   справки, дословная цитата. Отчёт субагента — данные, не истина: он ошибается в формулировках.
6. **Черновик плана в файл** `docs/<дата>_<тема>-plan.md`: стоп-вопросы → варианты с вердиктом → календарь → шаги
   с «кто» → метрики проверки. Факт — со ссылкой и датой, иначе **[гипотеза]** со способом проверки.
7. **Злой редактор** по файлу: где ошибается, что упущено (дешевле/оригинальнее), порядок, вердикт по каждому варианту
   одной строкой. Ограничение ≤ 600 слов, файлы не правит.
8. **Переписать план** (v2) с учётом редактора — но не слепо: владелец может перевернуть вывод редактора
   (было: «не гнаться за топ-моментами» → владелец: «нарезки топа набирают 300к, делать и топ, и тир-2»).
9. **Записать ВСЁ, чтобы не потерялось** (владелец спросит «ты всё записал?»):
   - план — решения и шаги;
   - **приложение к плану** — всё из отчётов разведчиков, что не вошло в решения (списки, конкуренты, шаблоны, тренды);
   - бэклог идей — новые строки, отложенные (`later`) и **отклонённые с причиной** (`rejected`);
   - плейбук/правила проекта — новые факты-правила;
   - STATE — итог сессии и решения владельца с датой.
10. **Раунд «автоматизация»**, если владелец хочет минимум участия: по каждому варианту — что делает человек
    (разово / ежедневно / еженедельно) и что можно отдать скрипту; проверить API, квоты, условия сайтов (запрет
    автоматического доступа — обходить нельзя, оставить клик человеку).

## Шаблон промпта разведчика

```
Ты — разведчик по теме «<тема>». Сегодня <дата>. Твои знания могут устареть — всё проверяй веб-поиском
(WebSearch/WebFetch), у каждого факта — ссылка и дата проверки; без источника помечай «гипотеза».

КОНТЕКСТ ПРОЕКТА: <3–5 строк: что делаем, аудитория, жёсткие ограничения, железо, что уже отвергнуто>.

ТВОЁ НАПРАВЛЕНИЕ: <одно>. Пункты: 1. … 2. … (4–6 конкретных вопросов, включая права/риски по направлению).

ВЫДАЧА (на русском, ≤900 слов): таблица «вариант → как добываем → права/риск (низкий/средний/высокий) → усилие →
свежесть/срок → как проверить на 1–3 штуках». + <списки/шаблоны по направлению>.
Ничего не скачивай, не устанавливай, никому не пиши — только разведка.
```

## Грабли

- **Лимит API (429) убивает всех разведчиков разом.** Не перезапускать новыми — возобновить каждого через
  `SendMessage` (контекст сохранён): «Лимит сброшен — продолжай с того места и сдай выдачу».
- Сайты отдают 403 ботам (HLTV, Reddit, Streamscharts, справки FACEIT) — разведчик помечает «не проверено»;
  ведущий не обходит защиту, а ищет первоисточник иначе или оставляет гипотезой.
- Находка не по направлению бывает важнее всего (правило о гэмблинге нашёл разведчик «свой контент») — просить
  в промпте: «важное вне направления — отдельным пунктом ГЛАВНОЕ».
- Разведчик предлагает действия от имени владельца (написать, зарегистрироваться) — это задачи владельцу в плане,
  не ведущему.
- Без раунда редактора план недооценивает **объём** (сколько единиц в неделю реально даст каждый источник) и
  **чьё время** уходит на ручные шаги.
