# Формат исходников под монтаж

## Главное правило

Качество не добавляется перекодировкой. «Скачать максимум, потом
перекодировать» — только лишнее поколение потерь. Правильный вариант
выбирается **при скачивании**; перекодировка — лишь страховка для
совместимости.

## Что брать

| Кодек видео | Монтаж на Intel-маке | Решение |
|---|---|---|
| H.264 (avc1) | везде | брать, из них — с наибольшим битрейтом |
| HEVC (h265, TikTok bytevc1) | Premiere/FCP открывают | оставить как есть |
| VP9 | тормозит или не открывается | перекодировать |
| AV1 (av01) | не открывается | перекодировать |

Звук: AAC. Opus — перекодировать. Дорожка — **оригинальная**: YouTube
добавляет автодубляж (en-US dubbed-auto), его не брать.

Факты с реальных роликов (2026-09-25):
- YouTube Shorts 1080×1920: H.264 ≈3000 кбит/с (m3u8, формат 270) и
  ≈2070 (137) > VP9 ≈1500 > AV1 ≈660. H.264 — и самый качественный, и
  самый совместимый. Дефолт yt-dlp выбирает AV1/VP9 — поэтому нужна сортировка.
- TikTok: только HEVC 1080p + AAC, выбора нет.

## yt-dlp

```
-S "lang,res,fps,vcodec:h264,vbr,acodec:aac" -f "bv*+ba/b" --merge-output-format mp4
```
`lang` первым — оригинальная дорожка; `res,fps` — не жертвовать разрешением;
`vcodec:h264` — предпочесть H.264; `vbr` — среди них самый жирный (иначе
возьмёт https-вариант с меньшим битрейтом вместо m3u8).
Проверить выбор без скачивания: `--print "%(format_id)s %(vcodec)s %(vbr)s %(acodec)s %(language)s"`.

## Страховочная перекодировка

Только если видео не H.264/HEVC или звук не AAC:
```
ffmpeg -i IN -map 0:v:0 -map "0:a:0?" -c:v libx264 -crf 16 -preset slow \
  -pix_fmt yuv420p -c:a aac -b:a 256k -movflags +faststart OUT.mp4
```
Годную дорожку — `-c copy`. Сохранить дату: `touch -r IN OUT`.
Скорость на этом маке: минута 1080p AV1 → H.264 ≈ 47 сек.
Пишет во временный файл, подменяет оригинал только при успехе.

## Проверка результата

```
ffprobe -v error -show_entries stream=codec_name,width,height -of csv=p=0 FILE
```
Ожидается `h264` или `hevc`, `1080,1920`, звук `aac`. Метаданные показывать
текстом, не скриншотами.

## Заливка в Shorts

Формат исходников на заливку не влияет — уходит смонтированный ролик,
его формат задаётся экспортом из монтажки.
