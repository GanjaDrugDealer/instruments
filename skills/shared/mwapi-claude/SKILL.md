# Claude через MWAPI

Базовый адрес OpenAI-совместимого API — `https://api.mwapi.dev/v1`. Один ключ работает со всеми моделями из `GET /v1/models` для его группы. Выбирай модель полем `model`. CDK из заказа активирует баланс в кабинете поставщика. Для запросов нужен API-ключ из раздела API Keys.

## Проверка и вызов из скрипта

Команды из папки скилла, Python 3.10+ без дополнительных библиотек:

```powershell
python -X utf8 scripts/mwapi.py models
'Reply with exactly: API OK' | python -X utf8 scripts/mwapi.py chat --model claude-haiku-5-5 --max-tokens 128
```

Скрипт берёт `MWAPI_API_KEY` из окружения процесса. На Windows при отсутствии переменной он открывает зашифрованный ключ из `%LOCALAPPDATA%\MWAPI\api-key.xml` под тем же пользователем Windows. В Python используй `read_api_key()` из `scripts/mwapi.py`, чтобы передать ключ напрямую в запрос к Open WebUI. На другой машине или в серверной автоматизации передай ключ из местного хранилища секретов. Ввод запроса через stdin, в stdout только список ID или текст ответа.

- Начни со списка моделей. Для коротких проверок подходит Haiku, для работы с текстом и кодом — Sonnet, для сложного разбора — Opus. Для автоматизации закрепи конкретный ID и проверь его на сохранённых примерах.
- Для OpenAI-совместимого клиента используй `POST /v1/chat/completions` и `Authorization: Bearer`. Непотоковый `POST /v1/responses` проверен тем же ключом. Для формата Anthropic используй `POST /v1/messages`, `x-api-key` и `anthropic-version: 2023-06-01`.
- При `401` проверь выбранный ключ и его статус. При `429` посмотри ограничения провайдера. Если список моделей меняется, сверяй ID по каталогу ключа. Списания смотри в [Usage MWAPI](https://api.mwapi.dev/usage).
- Держи ключ вне репозитория, истории команд и журналов. Для пробного запроса используй короткую фразу без данных проекта.

## Open WebUI

Используй существующий экземпляр и подключи MWAPI как отдельный источник моделей рядом с Ollama.

1. В административных настройках открой **Connections → OpenAI → Add Connection**. Укажи `https://api.mwapi.dev/v1`, ключ MWAPI и тип **Chat Completions**, если есть выбор. Пустое поле **Model IDs** включает автоматическое обнаружение. Если нужны только Claude или отдельные версии, укажи нужные ID из запроса к каталогу MWAPI.
2. Для автоматизации в проверенной версии Open WebUI 0.12.4 используй локальные `GET /openai/config` и `POST /openai/config/update` с действующим ключом администратора **Open WebUI**. Обновление заменяет всю конфигурацию OpenAI, поэтому сохрани остальные URL, ключи и настройки по их индексам. Для MWAPI включи подключение и общий переключатель `ENABLE_OPENAI_API`. Ответы обоих маршрутов содержат ключи. Печатай только статус, адреса провайдеров или ID моделей.
3. Проверь `GET /api/models` под нужной учётной записью. Убедись, что Claude появился, а существующие локальные модели видны. Отправь короткий запрос в новом чате или через `POST /api/chat/completions` и проверь полученный текст.

Подключение администратора может стать доступно другим пользователям этого экземпляра. При общем использовании выбери подходящий для проекта способ ограничения доступа. Проекты `Local` используют локальные модели согласно правилам этих проектов. Облачный чат передаёт запрос и включённый контекст в MWAPI.

### Доступ с телефона в local-gpt

Адрес для владельца, профиль VPN и команды запуска описаны в `docs/REMOTE_ACCESS.md` проекта local-gpt. Проверь задания `local-gpt-webui`, `local-gpt-caddy` и `local-gpt-tunnel`. Запусти остановленные задания штатным способом. Через внешний HTTPS-адрес проверь `/health`, страницу входа, список моделей и короткий ответ Claude. Для входа с телефона владелец подключает указанный VPN и использует свою учётную запись Open WebUI с 2FA.
