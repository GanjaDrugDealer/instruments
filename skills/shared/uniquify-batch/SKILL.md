# Пакетная уникализация папки

Скрипт лежит в `scripts/` этого скилла: `scripts/2026-09-22_uniquifier-mac.command`
(дальше `<скилл>` — папка этого скилла, в проекте обычно `.claude/skills/uniquify-batch`).
Этот скрипт — только macOS, нужен zsh (Windows — раздел «Windows» ниже). ffmpeg/ffprobe скачиваются сами при первом запуске
в `~/.uniquifier/bin`. Запускается headless — без диалогов, всё флагами.

Источник скилла — общая библиотека
`~/Desktop/AI Projects/_instruments/skills/shared/uniquify-batch`.
Править там, в проекты копировать папку целиком (без симлинков).

## Windows (с 2026-10-04)

Те же флаги и те же функции, другой скрипт: `scripts/2026-10-04_uniquifier-win.py` (Python, ffmpeg из PATH,
`FFMPEG_DIR` или соседнего `download-script\bin`; ничего не качает). Для двойного клика (диалоги) —
`scripts/2026-10-04_uniquifier-win.bat`. Кодировщик: `h264_nvenc` на видеокарте NVIDIA (RTX 5080), иначе
`libx264`; принудительно — `--encoder=nvenc|x264`. `--jobs=N` — несколько роликов одновременно (по умолчанию 1:
порядок вывода как на маке). В выходе нет подписи кодировщика (теги `encoder`, `Lavf`/`Lavc`, SEI x264).

```
python -X utf8 "<скилл>\scripts\2026-10-04_uniquifier-win.py" --keep-name --skip=scale,flip -o "<папка>\Unique" "<папка>\Source\a.mp4" ...
```

- Файлы перечисляются явно (в PowerShell/cmd нет `Source/*.MOV` как в zsh): `Get-ChildItem Source\* -Include *.mp4,*.mov`
  и подставить пути, либо дать скрипту список аргументами из `python`-однострочника в файле.
- Запускать в фоне (`run_in_background`), ждать уведомления. Статус: число файлов в папке выхода (последний ещё пишется);
  дата файла случайная, `-t` по времени не годится. Остановка: остановить фоновую задачу, затем
  `taskkill /F /IM ffmpeg.exe` и `Get-Process python | Stop-Process` (только свои); недоделанный файл — по сегодняшней дате.
- Тесты после правки: `python -X utf8 "<скилл>\scripts\2026-10-04_uniquifier-tests.py"` (≈20 сек, код 0 = всё прошло;
  19 проверок, в том числе обе версии кодировщика и отсутствие подписи).
- На Windows `render.py` youtube-shorts-cs зовёт этот же скрипт с `--only=color,noise,speed --keep-name`.
- Дальше в этом файле команды для мака (`zsh ...command`, `pkill`, `ls | wc -l`); на Windows их заменяют строки выше.

## 1. Перевести слова пользователя во флаги

| Пользователь говорит                    | Флаг                          |
|-----------------------------------------|-------------------------------|
| «не растягивать до 1080», «без масштаба» | исключить `scale`             |
| «не отражать», «без зеркала»            | исключить `flip`              |
| «без поворота / шума / цвета / скорости / кропа» | исключить `rotate` / `noise` / `color` / `speed` / `crop` |
| «только цвет и поворот»                 | `--only=color,rotate`         |
| «не менять имена», «оставить названия»  | `--keep-name`                 |

Всё исключаемое — одним флагом через запятую: `--skip=scale,flip`.
`--only` и `--skip` вместе нельзя — скрипт упадёт.
«Отразить» = горизонтальное зеркало. Дата создания рандомизируется всегда.

## 2. Проверить вход и выход

- Исходники: `ls "<папка>/Source"` — MP4 и MOV (с айфона обычно `*.MOV`).
- Выходная папка по умолчанию — `Unique` рядом с `Source`, если пользователь
  не назвал другую. Если в ней уже что-то лежит — спросить, а не затирать.
- С `--keep-name` одинаковые имена перезапишутся — выход должен быть пустым.

## 3. Запуск

Одной командой, **в фоне** (в Claude Code — `run_in_background: true`,
timeout 600000). 26 роликов шли ≈15–20 минут на Intel-маке:

```bash
cd "<папка с Source>" && mkdir -p Unique && zsh "<скилл>/scripts/2026-09-22_uniquifier-mac.command" --keep-name --skip=scale,flip -o "$PWD/Unique" Source/*.MOV 2>&1 | tail -30
```

Сказать пользователю одной фразой, что отключено/включено и куда падает
результат, и ждать уведомления о завершении — не опрашивать.

## 4. Статус (если спросят)

`ls "<выход>" | wc -l` — число файлов. Последний из них ещё пишется,
так что готово = N−1. `ls -t` для «какой сейчас» не годится: скрипт
ставит файлам случайную дату.

## 5. Остановка (если скажут «стоп»)

Остановить фоновую задачу (в Claude Code — `TaskStop` по её id), затем добить
остатки: `pkill -f uniquifier-mac.command; pkill ffmpeg`.
Недоделанный файл узнаётся по сегодняшней дате изменения (готовым ставится
случайная дата 2026-02…09). Удалять — только с согласия, и в Корзину
(`mv … ~/.Trash/`), не `rm`.

## 6. Итог

Из вывода взять строку `Готово: N из M`; при ошибках — `errors.log` в
папке выхода. Ответ пользователю: сколько готово, где лежат, что включено,
что выключено. Без скриншотов, без технических подробностей.
Если в проекте есть `STATE.md` — записать строку в «Сделано».

## Если нужна новая опция

Правка скрипта → новый тест в `scripts/2026-09-25_uniquifier-tests.sh` →
прогон `zsh <скилл>/scripts/2026-09-25_uniquifier-tests.sh` (≈10 сек,
код 0 = всё прошло) → только потом боевой запуск. Так был добавлен `--keep-name`.
Правку делать в библиотеке и разнести копии: в проекты, где лежит скилл,
и в `mac-local/scripts/` (оттуда работает лаунчер на рабочем столе).
