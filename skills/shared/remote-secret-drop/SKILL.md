# Передача секретов с телефона через одноразовую HTTPS-страницу

Поднимает на сервере пользователя временный одноразовый HTTPS-приёмник на случайном пути (`/<secret>`), открытый до первого успешного сохранения или истечения TTL (по умолчанию 10 минут). После ввода форма сама сохраняет ключи в `.env` (права `0600`), завершается, удаляет временный скрипт и закрывает временный порт в `ufw`. Секреты не попадают в чат, историю сессии, логи и сторонние сервисы.

## Правила безопасности

- **Не вводить и не печатать секреты** в чат, stdout и логи: при проверке `.env` смотри только права, владельца и имена ключей (`cut -d= -f1`).
- **Проверяй свободный порт** до запуска (на хосте с эфемерным диапазоном `10000+` бери порт ниже `10000`, по умолчанию `8450`, если он не занят).
- **Предпочитай доверенный сертификат (`--cert` и `--key`)** и домен сервера, чтобы мобильный браузер открывал ссылку без предупреждений. Ключ `--self-signed` используй только на сервере без домена и сертификата (потребуется подтвердить исключение в браузере).
- Всегда проверяй доступность ссылки снаружи (`EXT_GET_STATUS: 200` и `WRONG_PATH_STATUS: 404`) перед тем как отдавать её пользователю.

## Запуск приёмника

Запусти из папки скилла (`python3 -X utf8 scripts/secret_drop.py` на Mac/Linux, `python -X utf8 scripts/secret_drop.py` на Windows):

```text
python -X utf8 scripts/secret_drop.py start \
  --host <IP_или_хост> --ssh-port <SSH_порт> --user <ssh_user> \
  --domain <домен_сертификата> --drop-port 8450 \
  --cert <путь_к_fullchain.pem> --key <путь_к_key.pem> \
  --env-file /opt/<проект>/.env \
  --field "BOT_TOKEN:Токен бота (от @BotFather):telegram_bot" \
  --extra-pin-key CLAIM_PIN
```

### Основные параметры `start`

- `--identity <путь>` — явный путь к приватному SSH-ключу (если не передан, берётся `~/.ssh/id_ed25519` при наличии). На Windows при кириллице в `%USERPROFILE%` скрипт автоматически использует `ssh` из Git Bash, если он установлен.
- `--field KEY[:Подпись[:валидатор]]` — можно повторять несколько раз. Валидаторы: `nonempty` (по умолчанию), `telegram_bot` (формат + проверка `getMe` через Telegram API), `tg_username`, `regex:<шаблон>`.
- `--extra-pin-key <KEY>` — при сохранении генерирует одноразовый 6-значный PIN, пишет его в `.env` и показывает пользователю на странице подтверждения (удобно для `/claim <PIN>` в боте).
- `--owner <user>` — владелец создаваемого `.env` (по умолчанию `--user`).
- `--ttl <сек>` — время жизни ссылки до автозакрытия (по умолчанию `600`).
- `--self-signed` — временный самоподписанный сертификат через `openssl`, если на сервере нет `--cert`/`--key`.
- `--no-ufw` — не трогать `ufw`, если порт уже управляется иначе.

При повторной записи в существующий `.env` скрипт обновляет только переданные ключи, сохраняя остальные строки файла.

## Проверка и досрочная остановка

После того как пользователь подтвердит ввод, проверь закрытие порта и наличие ключей (без значений) и при необходимости останови приёмник вручную:

```text
python -X utf8 scripts/secret_drop.py status --host <IP> --ssh-port <SSH_порт> --user <ssh_user> --drop-port 8450 --env-file /opt/<проект>/.env
python -X utf8 scripts/secret_drop.py stop --host <IP> --ssh-port <SSH_порт> --user <ssh_user> --drop-port 8450
```
