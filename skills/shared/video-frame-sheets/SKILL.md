# Листы кадров из видео

Агент не смотрит видео — только картинки. Поэтому из ролика берутся несколько
кадров и склеиваются в лист: одна строка = один ролик, 4 ролика на лист.
Один лист открывается за раз и стоит как одна картинка.

## Команда

Запускать **из корня проекта** — кадры пишутся в `data/frames/`, листы в `out/sheets/`:

```
zsh <этот скилл>/scripts/make-sheets.sh "<папка с роликами>" [роликов_на_лист=4] [кадров=5]
```

- `out/sheets/sheet_N.jpg` — листы.
- `out/sheets/index.txt` — какой ролик в какой строке и на каких секундах кадры.
  Имён на листах нет (фильтр `drawtext` в сборке evermeet падает) — сверяться по index.
- Имя ролика в index обрезается до `IMG_1234`: если файлы уже подписаны,
  подпись не попадает в поле зрения — оценка остаётся слепой.

Длительность берётся через `mdls` (macOS). На другой ОС — заменить на ffprobe.

## ffmpeg

Ищется так: `$FFMPEG` → `bin/ffmpeg` в корне проекта → PATH.
На Intel-маке пользователя Homebrew не работает: статический бинарник (evermeet.cx)
лежит в `bin/` проекта. Homebrew не предлагать.

## Как выбираются кадры — по пикам движения

`scripts/motion-peaks.py`: ffmpeg считает разницу соседних кадров (4 кадра/с, 160 px),
берутся N самых сильных всплесков с разрывом ≥3 с, каждый сдвигается на +0,5 с —
к моменту, когда движение уже зафиксировано. Мало движения — добивается равномерно.
Последние `TAIL` секунд (по умолчанию 5) пропускаются — там бывает служебная концовка.
Анализ ≈ 4 с на 40-секундный ролик.

**Почему не равномерно.** Жест руками живёт 1–2 с. При 5 равномерных кадрах на 40 с
шаг ≈ 6,5 с — шанс поймать жест ≈ 25–30%. На практике равномерные кадры пропустили
«ОК» и палец вверх; пики движения их нашли.

## Точечная перепроверка одного ролика

Когда по листу не ясно — сетка 1 кадр/с на весь ролик (≈3 тыс. токенов):

```
<ffmpeg> -v error -y -i <ролик> -vf "fps=1,scale=-2:180,tile=8x5" -frames:v 1 check.jpg
```

8×5 = 40 кадров → ролик до 40 с. Длиннее — `fps=0.5` или `tile=8x8`.

## Цена

- Лист 4 ролика × 5 кадров (высота 260) ≈ 3 тыс. токенов.
- 26 роликов ≈ 7 листов ≈ 20–25 тыс.
- Не открывать кадры по одному, не делать скриншотов — только листы.

## Известные слабости

- Кадр +0,5 с от пика иногда ловит руку уже на спаде. Улучшение — 2 кадра на пик
  (до и после), ≈ ×1,5 токенов.
- В коротких роликах (<30 с) служебная концовка бывает длиннее `TAIL`.
- Звука нет. Всё, что держится на голосе, по листам не определить.
