# Структура проекта

Вход в проект — `CLAUDE.md` с картой. В `STATE.md` оставь следующий шаг, стадию и зависимости каждой активной задачи. Первый устойчивый факт сразу запиши в справочник темы и добавь его в карту. Для проверки размеров запусти из корня проекта `python -X utf8 "<путь к _instruments>/scripts/check-structure.py" --context .`.

| Задача | Открыть |
|---|---|
| Повторный вопрос или знакомый сбой | [Поиск и создание карточки](references/cards.md) |
| Передача смены, новая тема, превышен размер Markdown | [Контекст, пороги и порядок переноса](references/context.md) |
| Создание проекта, выбор папки, имя файла, секреты | [Структура и ограничения](references/layout.md) · для создания проекта открой скилл `new-project` |
| Установка скилла, подключение агентов, dsh, синхронизация с Cowork | [Подключение и доставка изменений](references/agents.md) |
