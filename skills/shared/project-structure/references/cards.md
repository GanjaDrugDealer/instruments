# Карточки в справочнике проекта

**Карточки для повторяющихся вопросов (25.11.2026, Стамбул).** Сначала найди ответ в действующем справочнике.
Если ответ уже собран в одном месте, достаточно понятного заголовка или ссылки на этот раздел из места, где его ищут.
Если для ответа на один и тот же вопрос агенту каждый раз приходится сводить сведения из нескольких мест,
собери короткую Markdown-карточку: вопрос словами пользователя, готовый ответ и ссылки на исходные разделы.
Карточка может быть разделом справочника. Из других мест ссылайся на неё, чтобы обновлять ответ в одном месте.

**Карточки разобранных сбоев (25.11.2026, Стамбул).** Ищи в справочнике проекта по словам пользователя или тексту ошибки.
При похожем симптоме возьми из карточки первую проверку и сверь результат с данными текущего запуска.
После подтверждения причины сохрани то, что ускорит следующий разбор: симптом, первую проверку и смысл её исходов,
причину, основание и способ проверить исправление (например, существующий тест). Обнови подходящую запись.
Если развилку стоит сохранить отдельно, создай короткую Markdown-карточку и дай на неё относительную ссылку
из раздела «По симптому» действующего справочника. Если подробности уже есть в разборе, достаточно ссылки на него.
