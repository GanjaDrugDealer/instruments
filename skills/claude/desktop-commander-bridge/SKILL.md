# Мост к машине: Desktop Commander и remote-devices

Общие правила русской Windows — в скилле `windows-ru-scripting`. Здесь только
то, что касается инструментов Claude.

## Какой инструмент рабочий

- `device_bash` на этой машине **не монтирует папки** — отвечает
  `no Plan9 drive shares mounted`. Не использовать и не делать из этого вывод
  «командной строки нет».
- Рабочий путь — Desktop Commander: `start_process` (PowerShell на самой
  Windows), `write_file`, `edit_block`, `read_file`, `list_directory`.
- `start_process` ждёт до `timeout_ms`; если процесс не успел — дочитать
  через `read_process_output`, а не запускать заново.
- Мост периодически отваливается и возвращается сам. В эти окна писать
  файлы в контейнер и думать; потом доставить.

## Где инструменты врут

- `device_commit_files` **иногда молча не перезаписывает** существующий файл:
  отвечает `written`, а на диске старая версия. После записи в существующий
  файл проверить содержимое. Маленькая правка — `edit_block` или
  Python-скрипт read-modify-write на машине. Файл целиком — коммитить в новый
  путь (например `_stage\`, новый путь пишется надёжно) и переносить на место
  командой на машине.
- `device_commit_files` пишет только в папки, подключённые к сессии. Цель вне
  них — через промежуточную папку внутри подключённой и `Move-Item`.
- Контентный поиск `start_search` шумный: совпадения внутри слов, первые строки
  вместо совпадений. Искать `Select-String` или Python-ом через `start_process`,
  либо забрать файл `device_stage_files` и грепнуть в контейнере.
- `read_file` не открывает лог смешанной кодировки — через `tail.py`
  из `windows-ru-scripting`.
- `interact_with_process` искажает кириллицу в путях — только файл скрипта.

## Экономия

- `list_processes` отдаёт все процессы машины — тысячи токенов. По имени —
  `Get-Process <имя>` или `taskkill /IM`.
- Рекурсивный `Select-String` по `C:\ProgramData` и подобным ловит
  однострочные JSON в мегабайты — вывод не влезет. Сужать папку и фильтр,
  обрезать строку.
- Несколько проверок — одним скриптом в одном `start_process`.

## Заблокированные команды

Desktop Commander по умолчанию блокирует `net`, `sc`, `reg`, `netsh`, `sudo`,
`shutdown` и подобные. Для служб — `Get-Service`, `Restart-Service`.
