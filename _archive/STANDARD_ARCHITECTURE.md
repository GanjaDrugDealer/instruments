# Стандартная Архитектура Проектов Antigravity

Каждый новый проект в экосистеме `Antigravity` должен придерживаться этой стандартизированной файловой структуры. Это обеспечивает консистентность, безопасность и позволяет автоматическим скриптам (таким как `collector.py`) корректно собирать инструменты.

## Структура Директорий

```text
MyNewProject/
├── .antigravity/         # [Системная папка] Настройки нейросети и среды
│   ├── GEMINI.md         # Описание стека, архитектуры и контекста проекта для ИИ
│   └── GUARDRAILS.md     # Жесткие правила безопасности (что агентам нельзя удалять)
├── agents/               # Промпты, роли и конфигурации специфичных для проекта агентов
├── mcp/                  # Код и конфигурации локальных MCP серверов проекта
├── skills/               # Скиллы (Antigravity Skills) специфичные для проекта
├── scripts/              # Утилиты: скрипты сборки, деплоя, тестирования (.py, .ps1, .sh)
├── src/                  # [Рабочая папка] Исходный код приложения
├── docs/                 # Документация, схемы (Mermaid), API спецификации
└── tests/                # Автоматизированные тесты
```

## Как это работает

1. **Изоляция ИИ от Кода:** Вся логика, связанная с ИИ (настройки, роли, скиллы, сервера), вынесена в папки `.antigravity`, `agents`, `mcp`, `skills`. Это не засоряет `src/`.
2. **Безопасность (Guardrails):** Наличие `GUARDRAILS.md` в корне каждого проекта гарантирует, что агент, запущенный в контексте этого проекта, прочитает правила и не удалит важные ключи или базы данных.
3. **Глобальный сбор:** Благодаря единому стандарту, скрипт-сборщик из `Instruments` всегда знает, откуда забирать полезные наработки в общую библиотеку.

## Автоматическое создание проекта

Чтобы не создавать эти папки вручную каждый раз, используйте генератор:

```powershell
# Пример запуска генератора
python "K:\Мой диск\AI Projects\Antigravity\Instruments\scripts\bootstrap_project.py" MyNewProject
```
Скрипт автоматически создаст всю структуру папок и сгенерирует базовые шаблоны `GEMINI.md` и `GUARDRAILS.md`.
